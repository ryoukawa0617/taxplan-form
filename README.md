# taxplan-form

EAST TAX会計事務所の「脱退一時金 所得税還付 お申込みフォーム」です（日本語・English・简体中文・한국어・Tiếng Việt・Bahasa Indonesia）。

公開URL: https://ryoukawa0617.github.io/taxplan-form/

- 画面は静的なHTML/JavaScriptだけで、入力内容は Google Apps Script の Web アプリに送信されます（送信先は `config.js`）。
- このリポジトリには申込データや個人情報は含まれていません。
- 元のソースは事務所内の `dattai-ichijikin-form/web/` です。ここを直接直した場合は、元のソースにも反映してください。
